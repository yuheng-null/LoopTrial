# 使用现有 Agent 做台架实验

先从对话取回目标、日常工况和写入授权。枚举、握手并阅读设备返回的信号单位、可写范围及动作说明。单次诊断可直接采一段波形。需要调参时，先读生效配置，在相同初态下运行基线。用基线解释选择的目标、硬约束、可比条件、候选上限和新试验确认次数。用 note 保存这次选择的依据。

写后检查独立回读。每个候选取得新波形，再依据响应决定下一步。给重试使用同一 key，给独立确认使用新 key。停机、回退或保留原配置时，记录最后成功的测量和当前能确认的设备状态。实际断线后应重新握手并读取配置。饱和归因需要输出确实到达上限、持续时间以及目标与反馈差距的证据。预算耗尽只适用于本次搜索。

CLI 的 discover 入口为 `looptrial devices` 和 `looptrial describe URI`。MCP stdio 命令为 `looptrial-mcp`。两种入口共享 LOOPTRIAL_HOME 指定的记录目录。命令行示例见仓库 README 和本目录 quickstart.md。
