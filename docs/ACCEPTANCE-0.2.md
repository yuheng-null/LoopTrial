## 离线复核

[23 份原始轨迹和波形](../evidence/race-v02/records.zip)含 7,146 个模型时间采样点、17 次有效完赛、5 次越界及 1 次超时。每个编号目录包含 `record.json`、`samples.csv` 和 `plot.svg`。将 ZIP 下载到当前目录，安装 LoopTrial 后可直接复核，无需浏览器或设备。

```powershell
Expand-Archive records.zip -DestinationPath checked-laps
looptrial review ./checked-laps/ff50e1b1873640848d61fb601c3f70e0
looptrial review ./checked-laps/af7553c08848427a859d10c7483b97cd
```

另有[独立几何复算程序](../examples/verify_yali_laps.py)。在源码根目录运行 `python examples/verify_yali_laps.py evidence/race-v02/records.zip`。现场裁判做轨迹线段与门平面的相交判断；独立程序将位置投影到跑道中心线，沿路线展开一圈的距离，计算经过扇区的顺序。两套算法对归档的每一条样本都复得相同的事件、门数、计时和偏离。遮住摄像头所见的标线、保持裁判地图不变时，回归试验观测到有效扫描行为零并越界。

**证据范围。** 本页的整车是主机 WebGL 模型，信号、物理参数和控制器均在软件中。Blue Pill 板上模型、USB 转串口和 BD-BT26 的实物记录另见[本版台架报告](../evidence/v02/board/README.md)。实体智能车性能和 SRDP 水中性能仍需在对应装置上测量。[复现实验与首次接入成本](RACE.md)
